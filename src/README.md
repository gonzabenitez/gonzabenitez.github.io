# 🎨 Next.js Frontend

A high-performance Bento-style interface built with Next.js 15.

### Key Features
- **Force-Dark UI**: Hardcoded dark theme to prevent "flash of light" on system-theme-aware devices.
- **Activity Sorting**: Projects are sorted by `last_pushed` date, not creation date, ensuring the most active work stays at the top.
- **Plexus Particles**: A custom Canvas-based interactive background that visualizes the "connectivity" of automated systems.
- **Responsive Grid**: Adapts from a complex 6-column Bento on desktop to a focused vertical stack on mobile.

### Development
```bash
cd src
npm install
npm run dev
```
